# Lab 2 - Starter

See the [lab task sheet](../README.md) for the full brief.

## Quick start

```
mvn test
```

This compiles the project and runs your tests in
`src/test/java/com/training/portfolio/AssetLineParserTest.java` - empty to
start with. Build out `MalformedAssetException.java` and
`AssetLineParser.java` following the comments at the top of each file,
writing your own tests as you go.

You should not need to edit `Asset.java` or `ParseSummary.java`.
