# Lab 2 - Starter

See the [lab task sheet](../README.md) for the full brief.

## Quick start

```
mvn test
```

This compiles the project and runs the pre-written tests in
`src/test/java/com/training/portfolio/AssetLineParserTest.java`. Implement
the `TODO`s in `MalformedAssetException.java` and `AssetLineParser.java`
until they all pass.

You should not need to edit the test file, `Asset.java`, or `ParseSummary.java`.
