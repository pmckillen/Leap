# Lab 1 - Starter

See the [lab task sheet](../README.md) for the full brief.

## Quick start

```
mvn test
```

This compiles the project and runs your tests in
`src/test/java/com/training/portfolio/PortfolioReportTest.java` - empty to
start with. Build out `PortfolioReport.java` following the comment at the
top of the file, writing your own tests in the test file as you go.

You should not need to edit `Asset.java`.
